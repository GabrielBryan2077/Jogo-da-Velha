# Tic-Tac-Toe / Jogo da Velha

HERE'S A BASIC GUIDE TO PLAYING THE GAME!!! (ENGLISH)

1. When you open the game menu, press any key to proceed.
2. After that, the game will ask for the names of both players (first Player 1 and then Player 2).
3. Type your name and press Enter to proceed.
4. Finally, here's the classic. Since it's a C# Console game, I had to improvise using numbers instead of a click function.
5. Type the position you want to use and press Enter to pass the turn to the next player.

AQUI ESTÁ UM GUIA BÁSICO PARA JOGAR!!! (PORTUGUÊS BRASILEIRO)

1. Ao abrir o menu do jogo, pressione qualquer tecla para prosseguir.
2. Em seguida, o jogo solicitará os nomes de ambos os jogadores (primeiro Jogador 1 e depois Jogador 2).
3. Digite seu nome e pressione Enter para prosseguir.
4. Finalmente, aqui está um clássico. Como se trata de um jogo de Console em C#, precisei improvisar usando números em vez de uma função de clique.
5. Digite a posição que deseja usar e pressione Enter para passar a vez para o próximo jogador.
